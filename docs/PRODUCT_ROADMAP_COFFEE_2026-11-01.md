# Gor's Coffee — продуктовый roadmap (обновлён 2026-11-01)

## 1. Продукт и ограничения
Публичный **демонстрационный** веб-сайт кофейни для портфолио Ruby on Rails. Первая целевая аудитория — посетитель (mobile-first), затем персонал/администратор. Цель — доказать end-to-end работу каталога и оформления **демозаказов**, а не заявлять о действующей кофейне, реальной доставке и приёме платежей.

## 2. MVP Release A — интерактивное меню
- Стартовые разделы: Coffee, Tea & Matcha, Iced Drinks, Bakery, Breakfast, Desserts; старые Pizza/Pasta сохраняются до отдельного решения.
- 15–25 демонстрационных товаров с названием, описанием, ценой, пищевыми флагами и доступностью.
- Категории, текстовый поиск без учёта регистра, фильтры; empty states; навигация с полной работой без JS.
- Респонсивные карточки, однозначные кнопки Add to cart и Details, безопасные Ruby/HTML templates.
- Серверная цена, проверка наличия. Никаких внешних фотографий без подтверждённых лицензий.
- Критерии: выбор категории, поиск и фильтрация корректны, отсутствие товара скрывает его, нет смешивания сессий, тесты/CI зелёные.

## 3. MVP Release B — варианты напитков, добавки
- Новые связанные таблицы через отдельные миграции: `product_variants` (объём, base_price_cents, currency), `modifier_groups`, `modifier_options`, `order_item_modifiers`, snapshot выбора и цены.
- Выбор S/M/L, обычного/овсяного/другого молока, шотов и сиропа; ограничения комбинаций, аллергенов и наличия.
- Итоговая цена только на сервере, в корзине фиксируется снимок конфигурации. Цена не зависит от подменённого запроса.
- Приёмка: одинаковая цена в конфигураторе, корзине, демозаказе; тесты валидации и изменений.

## 4. MVP Release C — оформление заказа
- Корзина с количеством, удалением, подсчётом; оформление **без реальных платежей**.
- Имя и контакт для демонстрации: только тестовые данные; способ получения — самовывоз; время и комментарий.
- Статусы `pending`, `accepted`, `preparing`, `ready`, `completed`, `cancelled`; права администратора, audit trail.
- Критерии: пользователь создаёт заказ, видит историю/статус, администратор обрабатывает, два пользователя не видят чужие заказы.

## 5. Release D — storefront и контент
- Главная: hero, преимущества, популярные позиции, категории, CTA, часы/адрес только при подтверждении реального бизнеса; иначе явные demo placeholders.
- Мобильная навигация, адаптивные карточки, modal/drawer, доступность (контраст, клавиатура, aria, alt), empty/loading/error states.
- Страницы об истории кафе, способах заказа, catering, FAQ; RU/EN опционально с проверкой переводов.
- Изображения только собственные/разрешённые, сохраняемые на persistent storage.

## 6. Release E — админка и качество
- Управление каталогом, вариантами, наличием, акциями, заказами, media; роли и политика доступа.
- Test-first безопасность, lint, CI; browser smoke, Lighthouse/axe; performance, DB indexes, pagination, N+1 audit.
- Поэтапное обновление Ruby/Rails/asset pipeline после зелёного старого baseline.

## 7. Deploy / Portfolio
- Изолированный Railway сервис и PostgreSQL (отдельно от других проектов), backups, healthcheck, logs, запрет реальных платежей без коммерческих условий.
- README RU/EN, архитектура, миграции, скриншоты реального UI, видео user flow, CI badge, даты и ограничения.
- Drive media assets для портфолио отдельно от приватных данных.

## Порядок и статус
P0 восстановление Docker/PG и 38 тестов на remote legacy baseline — PASS. Локальная Rails 6.0.6.1 интеграция, avatar/layout, настоящая JS сборка и localhost:3001 — pending. Этот PR — первый вертикальный срез Release A, без миграций и без вмешательства в локальные незакоммиченные файлы.
